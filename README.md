Project Overview
Target Career Pathway: Business/Data Analyst roles

Industry: Apparel and Fashion Retail (NAICS 458 — Clothing, Clothing Accessories, Shoe, and Jewelry Retailers)

Target Audience: BU MET students exploring analytics career paths

Product Question
Which skills are most valued for business/data analyst roles in apparel retail, and how well does our team's current skill set match those demands?

Team Contributions
This project was built through close, ongoing collaboration rather than a strict division by task. The team met regularly throughout the semester to assign that week's work, review each other's pages before merging, and keep the site consistent in tone and structure from page to page. Work rotated across data preparation, analysis, and website development rather than being owned by a single person in any one area, so every team member can speak to the full product, not just one section.
