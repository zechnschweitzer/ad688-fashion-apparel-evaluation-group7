Skill Gap Analysis

Overview

This page compares the skills most commonly requested in our filtered apparel and fashion analytics job postings with the team’s current skill levels, highlighting where the team is well-positioned and where gaps remain.

Code 
import ast
import os

import plotly.express as px
import plotly.graph_objects as go
from collections import Counter

clean_df = pd.read_csv("data/processed/apparel_analyst_clean.csv")

os.makedirs("figures/skill_gap_analysis", exist_ok=True)

PLOTLY_TEMPLATE = "plotly_white"
PLOTLY_COLOR = "#2C6E8C"

Most In-Demand Skills

Skill fields were parsed from each posting’s listed skills. Counts reflect how many of the 19 filtered postings mention each skill at least once.

Code 
clean_df["SKILLS_LIST"] = clean_df["SKILLS_LIST"].apply(ast.literal_eval)

all_skills = [
    skill
    for row in clean_df["SKILLS_LIST"]
    for skill in row
]

skill_counts = Counter(all_skills)

top_skills = (
    pd.Series(skill_counts)
    .sort_values(ascending=True)
    .tail(15)
)

fig_top_skills = px.bar(
    x=top_skills.values,
    y=top_skills.index,
    orientation="h",
    template=PLOTLY_TEMPLATE,
    color_discrete_sequence=[PLOTLY_COLOR],
    labels={
        "x": "Number of Postings Mentioning Skill",
        "y": "Skill"
    },
    title="Most In-Demand Skills in Apparel Analytics Postings"
)

fig_top_skills.update_layout(
    title_x=0.5,
    height=500
)

fig_top_skills.write_image(
    "figures/skill_gap_analysis/top_skills.png",
    scale=2
)

fig_top_skills.show()

We pulled the skills listed in each posting and counted how often each one showed up across our 19 filtered postings. Power BI and SQL came out on top with 7 postings each. Python and Microsoft Excel followed with 5 postings each and Digital Marketing appeared in 4. The remaining skills each appeared in 2 to 3 postings, reflecting a mix of technical, analytical, and communication skills expected across these roles.

Skill Gaps

We convert each skill’s share of the 19 postings into a target proficiency level, then compare that target against the team average to flag priority.

Code 
skill_map = {
    "Power BI": "Power BI",
    "SQL": "SQL (Programming Language)",
    "Python": "Python (Programming Language)",
    "Excel": "Microsoft Excel",
    "Digital Marketing": "Digital Marketing",
    "Stakeholder Mgmt": "Stakeholder Management",
    "Project Mgmt": "Project Management",
    "Data Analysis": "Data Analysis",
}

demand_pct = {label: skill_counts.get(full, 0) / len(clean_df) * 100 for label, full in skill_map.items()}

def target_level(pct):
    if pct >= 30:
        return 5
    elif pct >= 20:
        return 4
    elif pct >= 10:
        return 3
    else:
        return 2

def priority(gap):
    if gap >= 1.5:
        return "High"
    elif gap > 0:
        return "Moderate"
    else:
        return "Low"

gap_summary = pd.DataFrame({
    "Skill": list(df_skills.columns),
    "Market Demand": [f"{demand_pct[s]:.1f}%" for s in df_skills.columns],
    "Target Level": [target_level(demand_pct[s]) for s in df_skills.columns],
    "Team Average": df_skills.mean().round(2).values,
})
gap_summary["Gap"] = (gap_summary["Target Level"] - gap_summary["Team Average"]).round(2)
gap_summary["Priority"] = gap_summary["Gap"].apply(priority)
gap_summary = gap_summary.sort_values("Gap", ascending=False).reset_index(drop=True)
gap_summary

Comparing market demand against team proficiency helps show where we’re well-covered and where the gaps actually are both as a team and for each of us individually.

As a team Power BI is our largest gap. It’s tied for the most in-demand skill in the market showing up in 7 of 19 postings but has the lowest average proficiency on the team at 2.75. SQL is the other most requested skill at 7 of 19 postings and fares a bit better with a team average of 3.25. Python is requested in 5 postings and also comes in low at 2.75. Excel and Data Analysis are the opposite story: both are in demand in the market and also where we rate ourselves strongest so there’s no real gap to address there.

Breaking this down by person the picture looks a bit different for each of us:

  • Alyssa rates Intermediate (3) in Power BI SQL and Python the three most in-demand technical skills and rates strongest in Data Analysis Stakeholder Management and Project Management (all 4). Power BI and SQL are her clearest priorities since they’re the two most requested skills in the market and she’s only at Intermediate in both.
  • Ankita follows a similar pattern also rating a 3 in Power BI SQL and Python with Digital Marketing as her lowest rating (2). Since Power BI and SQL have the highest market demand those are the higher priority gaps for her compared to Digital Marketing.
  • Sara has the largest individual gap in Power BI rating herself a 2 (Beginner) the lowest score on the team for the most in-demand skill and she’s also lowest on Python (2). She’s strongest in Excel (5) and rates highly in Digital Marketing Stakeholder Management and Data Analysis (all 4).
  • Zech has the strongest overall technical profile on the team rating Advanced (4) in SQL Project Management and Data Analysis. His lowest ratings are Power BI and Digital Marketing (both 3) making Power BI his one real gap relative to the market’s top-requested skill.

Improvement Plan

Based on the gaps above our individual priorities are:

  • Alyssa and Ankita should prioritize Power BI and SQL before the Module 5 deadline, since both are currently at Intermediate despite being the two most requested skills in the market. Microsoft’s free Power BI learning path along with practicing SQL queries against the team’s own filtered dataset would tie skill-building directly to the project.
  • Sara should prioritize Power BI first, before the Module 5 deadline, since it’s the team’s lowest individual rating on the market’s most in-demand skill, followed by Python. Given her existing strength in Excel a Power BI path that builds on familiar spreadsheet concepts (for example Microsoft’s Excel-to-Power-BI transition materials) may be the fastest route in.
  • Zech should prioritize Power BI before the Module 5 deadline, the one skill where his rating trails his otherwise strong technical profile. Given his existing SQL proficiency focusing on Power BI’s data modeling features is a natural next step since those build on relational concepts he already knows.

Across the team Power BI is the most consistent gap since every member rated it at 3 or below while it ties for the highest market demand. Team members with relatively higher proficiency in a given skill (for example Zech in SQL and Sara in Excel) can informally support others when related project tasks come up rather than treating skill-building as separate from the coursework itself.
